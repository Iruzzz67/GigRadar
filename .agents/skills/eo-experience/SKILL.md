# EO Experience

## Priorities
1. Create and publish events with minimal friction.
2. Find suitable Artists.
3. Compare applicants using useful information.
4. Manage selections, communication, and event status.
5. See operational information at a glance.

## UX rules
- Separate event creation from event management when that improves clarity.
- Make event status and next action obvious.
- Show artist profile, skills, experience, availability, and relevant portfolio information where the existing domain supports them.
- Never expose Artist-only controls to EOs.
- Protect destructive actions with confirmation.
- Make validation actionable and preserve valid input.

## Quality checks
- Draft/empty/loading/error states.
- Search/filter/sort states.
- Pagination/infinite-scroll behavior where existing architecture supports it.
- Clear applicant status and feedback.
