# Artist Experience

## Priorities
1. Discover relevant opportunities quickly.
2. Understand gig requirements, location, date, compensation, and status.
3. Apply with confidence.
4. Maintain a compelling professional profile.
5. Track applications and upcoming commitments.

## UX rules
- Surface important gig metadata early.
- Make eligibility/requirements obvious.
- Preserve entered form data on recoverable validation errors.
- Show application state clearly: draft, submitted, under review, accepted, rejected, cancelled, or equivalent existing states.
- Never expose EO-only controls to Artists.
- Avoid dead-end screens; provide a next action or useful navigation.

## Quality checks
- Empty state when no gigs match.
- Loading state for lists/details.
- Error state with retry.
- Confirmation for destructive/costly actions.
- Accessible forms and validation messages.
